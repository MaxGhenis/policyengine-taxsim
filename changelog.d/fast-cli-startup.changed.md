`policyengine-taxsim --help`, `--version` and each subcommand's `--help` no longer import policyengine-us, so they return in about a second instead of 20 seconds or more. Importing `policyengine_taxsim` no longer imports policyengine-us either: `export_household`, `runners.PolicyEngineRunner` and `runners.StitchedRunner` load it on first use. Until something loads it, library code doesn't get policyengine-us's process-wide filter that ignores every warning, so `generate_household`, for example, now shows its S-corp NIIT warning on policyengine-us releases before 2.10.1. Command runs are unchanged, except that Ctrl-C while policyengine-us is still loading now prints "Aborted!" and exits 1, as it already did later in a run.
